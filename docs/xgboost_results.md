# XGBoost Results

## Data and preprocessing foundation

The experiment uses the corrected shared data foundation:

| Split | Rows | Transformed features |
|---|---:|---:|
| Train | 79,685 | 39 |
| Validation | 19,922 | 39 |
| Frozen test | 82,332 | 39 |

The model uses `artifacts/preprocess_tree.joblib`. The artifact is loaded and
used with `transform()` only; it is not refitted by the XGBoost workflow.
The processed splits have no exact predictor overlap across train,
validation, and test in the corrected foundation.

## Methodology

XGBoost uses `XGBClassifier` with `tree_method="hist"`, `random_state=42`,
`n_jobs=-1`, `scale_pos_weight=1`, `gamma=0`, and `eval_metric="aucpr"`.
During tuning, candidates use an `n_estimators` ceiling of 2,000 and
`early_stopping_rounds=50` against the validation split. Validation PR-AUC is
computed with sklearn's `average_precision_score` and is the primary selection
metric; validation ROC-AUC is the tie-breaker. Classification metrics use a
fixed probability threshold of 0.5.

The frozen test set is not used for tuning or model selection.

## Round 1 staged tuning

Round 1 contained 49 fitted configurations:

| Stage | Fits |
|---|---:|
| Baseline | 1 |
| Structure | 12 |
| Sampling | 18 |
| Regularization | 12 |
| Learning rate | 6 |
| **Total** | **49** |

The default baseline reached validation PR-AUC `0.983993` and ROC-AUC
`0.985793`. The staged search progressively identified max depth 10,
min-child weight 1, full row sampling, and 0.6 column sampling as a strong
region. The best regularization candidate used `reg_lambda=1`, `reg_alpha=1`
and achieved validation PR-AUC `0.985938`, ROC-AUC `0.987283`, and
`best_iteration=282`.

The learning-rate stage reproduced the same result at `learning_rate=0.1`.

## Round 2 joint search

Round 2 tested the focused Cartesian grid jointly across the interacting
hyperparameters:

```text
max_depth          = {8, 10}
min_child_weight   = {1, 5}
subsample          = {0.85, 1.0}
colsample_bytree   = {0.6, 0.8}
reg_lambda         = {1, 5}
reg_alpha          = {0, 1}
learning_rate      = {0.1}
```

This produced `2 × 2 × 2 × 2 × 2 × 2 = 64` fits. The Round 1 winner was
reproduced as the Round 2 winner with the same validation PR-AUC `0.985938`
and ROC-AUC `0.987283`.

## Final locked configuration

The final model was refit on the training split only, without a validation
`eval_set` and without early stopping. The selected tuning
`best_iteration=282` maps to `n_estimators=283` for the final refit.

```text
n_estimators       = 283
max_depth          = 10
min_child_weight   = 1
subsample          = 1.0
colsample_bytree   = 0.6
reg_lambda         = 1
reg_alpha          = 1
learning_rate      = 0.1
scale_pos_weight   = 1
gamma              = 0
tree_method        = "hist"
random_state       = 42
n_jobs             = -1
```

## Reproducibility

The workflow uses `random_state=42`, the frozen tree preprocessing artifact,
the corrected split sizes above, and the preserved tuning logs. The complete
tuning history contains 113 fits: 49 Round 1 fits and 64 Round 2 fits.
Final outputs are generated by `src/07_xgboost.py --stage final` after the
configuration is locked. The final model is saved in both joblib and native
XGBoost JSON formats.

## Limitations and finalized downstream analysis

Selection is based on one fixed validation split, and the local test metrics
are reference outputs rather than a basis for tuning. No claims about causal
performance differences are made here. The finalized
[standardized evaluation](standardized_model_evaluation.md) covers threshold
analysis and cross-model comparison; the [diagnostics report](diagnostics_report.md)
covers SHAP, calibration, drift, and TTL ablation; and the
[RF/XGBoost advanced analysis](rf_xgboost_advanced_analysis.md) covers
efficiency benchmarking and bootstrap uncertainty for the two tree models.
